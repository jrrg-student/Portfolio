# Portfolio template for P1 Gold

A ready-to-go portfolio page for P1 Gold. The spec wants each of us to have our own page with
our name, what we built, and the tech we used, and to link it in DESIGN.txt. This is mine with
your name on it and a draft of what you built.

## What to edit

Open `index.html` and search for `EDIT`. There are three spots:

1. **Your GitHub link** in the header.
2. **What I built.** I drafted it from your commits in our repo. Fix anything I got wrong and
   add anything I missed.
3. **The itch.io button.** It links our team's itch.io page. Swap in your own link if you upload
   the game separately.

The screenshot is `images/zelda-custom-level.png`. Replace it with your own if you like, but
keep the same file name.

## Put it on GitHub Pages

1. On GitHub, make a new **public** repo (for example `Portfolio`).
2. **Add file → Upload files**, drag in everything in this folder (keep the `images` folder),
   and commit to `main`.
3. **Settings → Pages → Build and deployment → Deploy from a branch**, pick `main` and
   `/ (root)`, then **Save**.
4. After a minute it's live at `https://YOUR-USERNAME.github.io/Portfolio/`. That's the link for
   DESIGN.txt and for #exhibition on Discord.

## Rules from the spec

- No source code on the page or in the repo. This folder is only the web page.
- Don't link to my page (we each need our own, and linking the partner's isn't allowed).
- itch.io can host the game, but it can't be the portfolio itself.
